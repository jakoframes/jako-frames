    Rig it in After Effects

    1. Import layers/ into a 1600×2000 comp, with 01 at the bottom and 09 on top.
    2. Set each layer's Anchor Point to its pivot from the cards above or rig.json. Then set Position to the same value so the layer stays in place.
    3. Parent face, hair and glasses to head. Then parent head, the arms and the legs to torso.
    4. Animate Rotation on the arms, legs and head. For a blink, swap in 05_face_blink.png for 2–3 frames. Hide glasses to show the eyes.
