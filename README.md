# jako.frames 🎬

Source for the [@jako.frames](https://instagram.com/jako.frames) reels — motion design made with **Claude AI**, in code instead of a timeline.

## Reels
| Folder | What it is | Built with |
|---|---|---|
| `reel-1k-cake` | 1K followers celebration with 3D Jako | Blender + Python |
| `reel-agents-dolomites` | Jako's AI agent team in a mountain office | Blender + Python |
| `claude-cooking-reel` | Claude "cooking" a SaaS promo in a white 3D studio | Remotion |
| `reel-find-skills` | Finding Claude skills | Remotion |
| `reel-what-the-heck` | Reaction cut with kinetic subtitles | Remotion |
| `elite-finance-reel` | Client reel | Remotion |
| `grand-point-reel` | Client reel | Remotion |

## Also here
- `jako-3d` — the 3D Jako character, built from the 2D kit with Blender scripts
- `guide-1k`, `Claude-Motion-Design-Guide.md` — guides on making motion with Claude
- `jako-hq.html`, `kinetic-type.html`, `logo-reveal.html` — HTML animations
- `.claude/agents` — the Claude agent team (caption writer, trend scout, analyst, video director, planner)

Rendered videos are not stored here — watch them on Instagram.

## Run a Remotion reel
```bash
cd claude-cooking-reel
npm install
npx remotion studio
```
