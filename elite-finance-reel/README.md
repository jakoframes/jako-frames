# Elite Finance — ипотека рилсі

- Финал: `exports/elite-finance-reel_v2.mp4` (1080×1920, 30fps, 85 с). v2: қайталанған «Міндетті түрде» алынды, кесулерде blur өту, ақ карточкалар бет астында, субтитр карточканың үстінде.
- Монтаж + субтитр мәтіні + тайминг: `plan/build.mjs` → `public/cut.mp4`, `src/data.json`
- Графика: Remotion (`src/`), рендер жүйедегі Chrome арқылы:
  `npx remotion render src/index.ts Main exports/<name>.mp4 --crf=16 "--browser-executable=C:\Program Files\Google\Chrome\Application\chrome.exe"`
- Превью кадрлар: `node plan/stills.mjs title+1.5 nauryz20+1`
